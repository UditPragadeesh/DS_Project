Hello this is a project done by me using some mock data. 
To Clear the Database and upload the mock tables as new run db.py
To run the app. Run Introduction.py using streamlit run.
Once you run your pages Introduction, View_Tables, CRUD_Operations, Sqlqueries, MyQueries, User_Introduction shoulb be listed on the left side.
Incase app fails to run check dependencies and libraries mentioned in requirements.txt
'1_View_Tables.py' has the code to show and filter tables for viewing
'2_CRUD_Operations' contains the code to do operations such as adding, removing or updating data in the database as a provider or receiver.
'3_sqlqueries' code to run view queries answered using sql code.
'4_MyQueries' has the code to view the queries by me with the code to answer them
'5_User_Introduction' my introduction on streamlit app
