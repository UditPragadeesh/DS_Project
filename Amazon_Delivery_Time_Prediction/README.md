
# Delivery Time Predictor

Using a machine learning Regression Model trained on historical data, I have created this web app which predicts time required for a delivery based on data provided.


## Features

- ###  Single Prediction: 

    Prediction of delivery time of one order at a by provividing details one by one as specified.
- ###  Mulitple Prediction

    Predicts delivery time for multiple orders if details of said orders are uploaded.

## RUNNING APPLICATION

To run app, use command

```bash
   streamlit run Delivery_Time.py
```
